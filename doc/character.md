# 角色系统

角色目录结构：

```text
characters/
  alice/
    alice.json
    config.toml
    cognition.json
    emotion.json
    portrait/
```

## 角色文件

- `alice.json`：角色主设定
- `config.toml`：角色级配置覆盖
- `cognition.json`：认知层缓存
- `emotion.json`：情绪层缓存

## 原则

- 角色设定决定语气、偏好和关系感
- 角色设定不应该替代当前话题来源
- 长期事件不要直接写进角色卡

## 多角色要求

- 不同角色必须有独立的记忆、认知、情绪
- 不要把角色、人类参与者、观众混成“用户/对方”
