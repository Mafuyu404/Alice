# 内在叙事流

实现文件：`kokoro/core/inner_stream.py`  
运行文件：`characters/{character_id}/inner_stream.txt`

内在叙事流是角色的连续主体状态。它描述“我现在作为我还在想什么”，包括心境、主注意、旁路注意、悬挂线索、外部输入态势、行动倾向和克制边界。

它不是：

- 计划表
- 兴趣权重表
- 长期人格设定
- 事实档案
- Python 可解析规则

## 位置

在生命周期架构中，内在叙事流位于事件和行动之间：

```text
InputEventBus
  → InnerStreamLoop 更新内在叙事流
  → 行动选择层读取内在叙事流
  → 行动结果回写事件
```

所有输入源都可以影响它：人的话、QQ 群、屏幕、网页、搜索结果、记忆、时间流逝、自身说话、沉默和工具结果。

## 稳定栏目

当前提示词要求输出七个栏目：

```text
【当前心境】
【主注意】
【旁路注意】
【悬挂线索】
【外部输入态势】
【行动倾向】
【克制与边界】
```

这些栏目给 LLM 阅读，不给程序写硬规则。行动层可以整体注入这段文本，让模型根据它选择 `say`、`wait`、`search_web`、`write_memory` 等行动。

## 更新节奏

`InnerStreamLoop` 负责节奏更新：

- 事件进入后短窗口合并，避免每条消息都刷一次 LLM。
- 没有新事件时产生轻量心跳，维持注意和行动倾向。
- 隐私事件不注入正文，只记录弱信号。
- 如果事件没有实质变化，可以保留旧流。

语音快速回应不等待内在叙事流更新；回应、沉默和后续工具结果都会作为事件回写，随后被异步吸收。

## 下游

这些能力都应优先读取内在叙事流，而不是各自发明动机：

- 说话 / 主动发言
- QQ 参与和表情包选择
- 搜索
- 记忆写入
- 认知更新
- 屏幕/网页观察
- 等待、旁听和沉默

## 原则

- 人类不是默认中心；人的话只是输入源之一。
- 群聊、网页、屏幕、时间和自身行动也都是生活现场。
- 行动倾向不是命令，行动层仍要考虑能力、安全、冷却和当前上下文。
- 搜索、说话、沉默、记忆和等待都属于角色生活，不是用户请求工具链。
