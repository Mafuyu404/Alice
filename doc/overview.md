# 框架概述

## 架构总览

Alice Chat 是一个桌面 AI 陪伴框架，围绕"语音对话 + 视觉呈现 + 环境感知 + 长期记忆"四个维度设计。用户通过语音或文字与角色互动，角色通过 TTS 语音回复并配合立绘表情变化，同时具备主动搭话和屏幕感知能力。

## 主要工作模式

### 语音模式（CLI）

`python cli.py` 启动完整的语音对话体验：

1. **STT 流式识别** — 通过 sherpa-onnx 实时识别麦克风输入
2. **对话池精炼** — 原始识别文本经过小模型修正错字后送入对话
3. **LLM 对话** — 携带角色设定、记忆、屏幕上下文生成回复
4. **TTS 语音合成** — 回复文本通过 MiniMax/Cartesia 转为语音播放
5. **立绘同步** — 后台线程根据对话情绪选择立绘表情
6. **主动搭话** — 空闲时根据冲动值模型触发角色主动说话
7. **屏幕监控** — 周期性截图分析，感知用户当前活动
8. **记忆事件** — 定期检查日期纪念日和记忆查询

### 文字模式（WebUI）

`python webui.py` 启动浏览器界面：

- FastAPI 后端提供 REST API + SSE 流式响应
- 纯文字对话，不涉及 STT/TTS
- 角色管理、模型切换、历史对话管理

## 配置机制

双层配置覆盖：`config.toml`（主配置，可提交 git）+ `config.json`（密钥，已 gitignore）。TOML 值优先，JSON 填充空值。详见 [config.md](config.md)。

## 角色系统

`characters.json` 定义角色名称、描述、性格、背景故事、关系设定、主动搭话指导。系统提示词由模板 `prompts.json` 中的 `character_system.template` 渲染生成。详见 [character.md](character.md)。

## 主要模块

| 模块 | 文件 | 功能 |
|------|------|------|
| 配置加载 | `kokoro/config.py` | 双层配置合并 |
| 角色管理 | `kokoro/character.py` | 角色加载与提示词构建 |
| 对话会话 | `kokoro/chat_session.py` | 对话历史管理、记忆注入 |
| LLM 客户端 | `kokoro/llm_client.py` | OpenAI 兼容 API 调用 |
| 语音识别 | `kokoro/stt.py`, `kokoro/pool.py` | STT 流式识别 + 精炼池 |
| 语音合成 | `kokoro/tts.py`, `kokoro/tts_*.py` | TTS 调度与多后端 |
| 记忆系统 | `kokoro/memory.py`, `kokoro/memory_events.py` | 长期记忆与记忆事件 |
| 主动搭话 | `kokoro/proactive.py` | 冲动值驱动的主动说话 |
| 屏幕识别 | `kokoro/screen_interest.py`, `kokoro/vision.py` | 截图分析与兴趣判断 |
| 立绘控制 | `kokoro/portrait_controller.py` | 立绘表情选择 |
| 立绘窗口 | `overlay_slideshow.py` | Qt 透明立绘窗口 |
| 提示词管理 | `kokoro/prompts.py` | prompts.json 加载与格式化 |

## 外部依赖

| 服务 | 用途 | 可选 |
|------|------|------|
| Ollama 或 OpenAI 兼容 API | LLM 对话 | 必选 |
| MiniMax / Cartesia | TTS 语音合成 | 是 |
| sherpa-onnx | STT 语音识别 | 是（语音模式） |
| mem0ai | 本地向量记忆 | 是 |
| DashScope / Ollama | 视觉识别 | 是（屏幕监控） |
| PySide6 | 立绘透明窗口 | 是 |
