# 多角色调度器

实现文件：

- `kokoro/multi_chat.py`

## 作用

在多人场景里决定：

- 谁说
- 对谁说
- 要不要沉默
- 是否继续 followup
- 是否使用页面或屏幕缓存

## 当前场景

- 普通多人聊天
- 多人直播
- 随机 MC 页面讲解

## 当前约束

- planner 必须只返回单个 JSON 对象
- planner 失败时允许 fallback
- 随机 MC 页面切换时，fallback 也必须强制转向当前页面

## 当前随机 MC 设计

- idle tick 不轻易沉默
- 页面切换时优先切到新页
- 讨论必须围绕当前网页缓存
- 不允许把旧页继续聊很久
